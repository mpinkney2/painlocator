# Pain level indicator — design origin

| | |
|---|---|
| Date | 2026-11-21 |
| Author | PainLocator project |
| Status | Original design |

The 0–10 pain level control in the patient shell is an original PainLocator design.

It is a numeric rating scale. The words are generic intensity bands: **No pain** (0), **Mild** (1–3), **Moderate** (4–6), **Severe** (7–9), and **Worst pain imaginable** (10). A single neutral face sits beside the number. The mouth and brows move only a few pixels as the number changes. The face is one drawing, not a row of colored faces. Intensity color is limited to the slider.

This indicator was drawn for PainLocator. It is not derived from the Wong-Baker scale, FPS-R, or any hospital poster. It does not copy a published face chart, a hospital name, or a hospital logo.

The body map remains the place where a patient marks location. The 0–10 control only records how strong the pain feels.
