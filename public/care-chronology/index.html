INTEGRATION ROADMAP

Epic / MyChart is not connected

This prototype demonstrates an isolated data model. A real integration will require patient-authorized SMART on FHIR OAuth, a registered application, health-system endpoint configuration, data provenance checks, security review, and consent handling.

MyChart message access and clinical write-back must be verified separately. No healthcare data is retrieved or sent from this demonstration.
