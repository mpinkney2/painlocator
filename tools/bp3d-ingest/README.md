# BodyParts3D ingest (PainLocator Phase 2 Slice 2)

Offline / build-time pipeline only. Does **not** change the production Spatial viewer.

## What is committed vs fetched

| Committed in git | Fetched / regenerated locally |
| --- | --- |
| Ingest scripts + docs | Full BodyParts3D zip (`data/bodyparts3d/cache/`) |
| `source-manifest.json` + per-OBJ SHA-256 pins | Mapping tables (`isa_parts_list_e.txt`, `isa_element_parts.txt`) |
| `ARCHIVE.sha256` (immutable pin) | Subset OBJ meshes |
| Optimized `skeletal.glb` / `muscle.glb` | `raw-pre-meshopt/` intermediates |
| `manifest.json`, `LICENSE.md`, `build-report.json` | |
| `fma-verification.json` (generated table, committed for review) | |

PainLocator is **not** a BodyParts3D mirror. Upstream archives stay out of git; SHA-256 pins are the source of truth even when the official URL says `LATEST`.

## Canonical PainLocator space

| Property | Value |
| --- | --- |
| Units | meters |
| Up | +Y |
| Handedness | right-handed |
| Facing | +Z anterior (toward default camera) |
| Laterality | +X = anatomical **right** |

### Source → canonical transform (validated)

BodyParts3D OBJ space is millimeters, Z-up, +X anatomical left.

```text
(x, y, z)_mm → (-x, z, -y) * 0.001
```

Validated on the left-shoulder pack: humerus centroid at ≈ (−0.19, 1.19, 0.07) → left / superior / slightly anterior. See `orientation-check.json` and `tools/bp3d-ingest/dev/orientation-preview.svg` (DEV only).

## Clean-checkout workflow

```bash
npm install                          # includes @gltf-transform/cli@4.1.1
pip install -r tools/bp3d-ingest/requirements-lock.txt

# Canonical one-shot rebuild (network required once for cache)
npm run bp3d:build

# Fast offline checks (no network; uses committed derived assets)
npm run bp3d:test
npm test
npm run typecheck
npm run build
```

Individual steps: `bp3d:fetch` → `bp3d:verify` → `bp3d:ingest` → `bp3d:optimize` → `bp3d:test`.

## Derived-asset policy

**Keep in git:** `skeletal.glb`, `muscle.glb`, `manifest.json`, `LICENSE.md`, `build-report.json`, `orientation-check.json`

**Do not commit:** `raw-pre-meshopt/*.glb` (regenerated by optimize), cache zip/OBJs/mapping tables

## CI strategy

| Suite | Command | Network | When |
| --- | --- | --- | --- |
| Fast app CI | `npm test` / `typecheck` / `build` | No | Every PR |
| Anatomy integrity | `npm run bp3d:test` | No | Every PR (via `npm test` hook) |
| Full source rebuild | `npm run bp3d:build` | Yes (first time) | Anatomy source updates, new packs, release validation |
